## 💻 Installation

PaperCake is available as a free Chrome extension download.

1. Open the **Releases** section of this GitHub repository.
2. Download the latest `PaperCake.zip`.
3. Extract the downloaded ZIP.
4. Open Google Chrome.
5. Navigate to `chrome://extensions`.
6. Enable **Developer mode**.
7. Click **Load unpacked**.
8. Select the extracted folder containing `manifest.json`.
9. Navigate to a supported MemeCoin trading platform and open a token trading page.

PaperCake should load its corresponding paper trading interface on supported pages.

**Keep the extracted extension folder on your computer.** Chrome needs access to those files to run the extension.

## 🔄 Updating PaperCake

To update PaperCake, download the latest release and replace the files in your existing extension folder, then reload the extension through Chrome.

Back up important paper trading data before reinstalling the extension or changing Chrome profiles.

PaperCake stores simulated trading information locally in Chrome.
